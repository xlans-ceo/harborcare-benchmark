# HarborCare — Benchmark

موقع تجريبي محلي لخدمات منزلية مصرية. يستخدم لتقييم قدرة التنفيذ فقط؛ ليس منتجاً قيد الإطلاق.

## المتطلبات

- Node.js v24 أو أحدث (تم التحقق من v24.22.1).
- لا توجد تبعيات npm؛ يستخدم المشروع `node:http` و`node:sqlite` و`node:crypto` و`node:test` فقط.

## التشغيل

```bash
npm start
```

أو:

```bash
node src/server.js
```

يعمل الخادم افتراضياً على `http://127.0.0.1:3000`.

### متغيرات البيئة (اختيارية)

| المتغير | الوصف | الافتراضي |
|---|---|---|
| `PORT` | منفذ الاستماع | `3000` |
| `DATA_DIR` | مجلد قاعدة البيانات | `./data` |
| `DEMO_PASSWORD` | كلمة مرور الحساب التجريبي | `demo1234` |
| `CONTACT_RATE_MAX` | عدد محاولات نموذج التواصل المسموح | `5` |
| `CONTACT_RATE_WINDOW_MS` | نافذة تقييد المحاولات (مللي ثانية) | `600000` |
| `LOGIN_RATE_MAX` | عدد محاولات تسجيل الدخول الفاشلة المسموح | `10` |
| `LOGIN_RATE_WINDOW_MS` | نافذة تقييد تسجيل الدخول (مللي ثانية) | `900000` |

## الاختبارات

```bash
npm test
```

أو:

```bash
node --test test/app.test.js
```

تستخدم الاختبارات قواعد بيانات SQLite مؤقتة منعزلة ومنافذ عشوائية؛ لا تتطلب إعداداً يدوياً.

## حساب تجريبي

- اسم المستخدم: `demo`
- كلمة المرور: `demo1234` (أو القيمة المحددة في `DEMO_PASSWORD`)

هذا الحساب وهمي محلي فقط. لا تستخدم معلومات حقيقية.

## حدود المدخلات والتحقق

### نموذج التواصل

- **الاسم:** ٢–١٠٠ حرف.
- **رقم الموبايل:** رقم مصري فقط. يقبل الصيغ `01[0125]XXXXXXXX` أو `+20...` أو `0020...`؛ تُحوّل الأرقام الهندية والمسافات والشرطات تلقائياً وتُخزّن كـ ١١ رقماً.
- **الخدمة:** اختيارية؛ إذا اختُيرت يجب أن تكون خدمة نشطة في قاعدة البيانات.
- **الرسالة:** ١٠–١٠٠٠ حرف.

### إدارة الخدمات

- **اسم الخدمة:** ٢–١٢٠ حرف.
- **التصنيف:** قائمة مغلقة (`سباكة`، `كهرباء`، `تكييف وتبريد`، `نجارة`، `دهانات وتشطيبات`، `تنظيف منزلي`).
- **الوصف:** ١٠–٥٠٠ حرف.
- **الحالة:** نشطة (`1`) أو غير نشطة (`0`).

### حدود الطلبات

- **حجم النص:** 16 كيلوبايت كحد أقصى؛ يُرجع `413` عند التجاوز.
- **نوع المحتوى:** يجب أن يكون `application/x-www-form-urlencoded`؛ خلاف ذلك يُرجع `415` للمسارات التي تتوقع نموذج.
- **محاولات تسجيل الدخول:** ١٠ محاولات فاشلة خلال ١٥ دقيقة لكل عنوان IP + اسم مستخدم.
- **محاولات التواصل:** ٥ محاولات خلال ١٠ دقائق لكل عنوان IP.

## بنية المشروع

- `src/server.js` — خادم HTTP والتوجيه.
- `src/db.js` — إعداد SQLite والبذور الأولية.
- `src/security.js` — الجلسات، CSRF، التجزئة، وتأمين الاستجابة.
- `src/validation.js` — التحقق من مدخلات النماذج.
- `src/views.js` — قوالب HTML المُعَدة جانب الخادم.
- `src/styles.css` — الأنماط والرموز اللونية.
- `src/ratelimit.js` — حدود محاولات نموذج التواصل.
- `test/app.test.js` — اختبارات الوظائف والأمان والاستمرارية.

## ملاحظات

- الموقع باللغة العربية مع اتجاه RTL.
- لا يوجد JavaScript جانب العميل افتراضياً.
- البيانات تُخزّن محلياً في `data/harborcare.db`.
- الحماية المطبقة (CSRF، التحقق من الأصل، حدود الطلبات) محلية وعملية فقط؛ لا تُعتبر جاهزة للإنتاج.
